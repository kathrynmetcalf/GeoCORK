## Installation

Windows, MacOS, and Linux:

Download the standalone release package for your system requirements found at [latest release](https://github.com/kathrynmetcalf/Geochronology_Code/releases/latest)

## Upgrading

Remove old standalone release package only, download new release package, open existing database file(s) in new release package. We strongly reccomend creating backups of any databases and previous release packages before upgrading.

## Requirements

All software requirements will be included in the standalone release package. We reccomend usage of any recent laptop or desktop to utilize the application and storage of the database and application on a SSD.
