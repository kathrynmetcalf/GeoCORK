Schema versions and upgrades
============================

When GeoCORK opens a database created by an older version, it offers to back it up and
upgrade the schema (see :mod:`util.database.create.Create_database`).

Known schema versions: v1.0.0, v1.0.1, v1.0.2, v1.0.3, v1.0.4, v1.0.5, v1.1.0.
