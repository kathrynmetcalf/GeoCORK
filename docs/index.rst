GeoCORK documentation
=====================

**GeoCORK** is a desktop application (PyQt6 + SQLite) for managing geochronological and
geochemical data: samples and their locations, aliquots, spots and grains, U-Pb and
geochemical analyses, references, tags, filters, plots, and exchange with SESAR/IGSN.
