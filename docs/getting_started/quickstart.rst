Quickstart
==========

1. **Open or create a database.** The landing page lists recent databases and can create a
   new, empty GeoCORK database.
2. **Import data.** Use the import wizard to load an Excel workbook (for example the
   U-Th-Pb in-situ template) and map its columns onto GeoCORK fields.
3. **Browse and edit.** The database tab shows each table; open a sample to see and edit
   its aliquots, spots, analyses and location.
4. **Filter and view.** Build filters to select samples or analyses, then view the results
   in the data viewer.
5. **Plot and map.** Open the sample map to see sample locations, and the plot dialog for
   U-Pb and geochemistry diagrams.
6. **Export.** Export selected data to a new database or a spreadsheet.
