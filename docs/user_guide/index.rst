User guide
==========

This guide walks new users through GeoCORK: opening or creating databases, then
importing, filtering, editing and exporting geologic and geochronologic data.

.. note::

   Adapted from the *GeoCORK User Manual* (version 1.0.5) by Jarrod Burges (Rutgers
   University) and Kathryn Metcalf (California State University, Fullerton). Features
   added after 1.0.5, such as geochemical analyses, the sample map, plotting and SESAR,
   are listed under *Newer features* and are still being written.
